# CV — Madi Kemel Dinga

CV personnel en HTML et CSS, conçu pour être consulté en ligne et imprimé au format A4.

## Consulter le CV

Ouvrir `index.html` dans un navigateur.

## Exporter en PDF

Dans le navigateur, utiliser `Ctrl + P`, choisir **Enregistrer au format PDF**, puis désactiver les marges et activer les arrière-plans si nécessaire.
